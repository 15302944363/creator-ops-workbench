# 达人运营工作台 · CreatorOps

X、YouTube、Instagram、TikTok 达人发现、建联与跟进的运营效率台。

## 在线访问

https://15302944363.github.io/creator-ops-workbench/

## 功能

- 四平台达人管道管理（YouTube / Instagram / TikTok / X）
- 可视化陪伴模式：当前任务、确认节点、风险提醒、跟进提醒
- 建联流程：批量选择达人 → 生成个性化草稿 → 人工确认后推进
- 桌面与移动端响应式适配
- 本地数据持久化（localStorage）

## 本地运行

```bash
pnpm install
pnpm dev
```

浏览器打开 http://127.0.0.1:5173

## 技术栈

React + TypeScript + Vite，纯前端，无后端依赖。
